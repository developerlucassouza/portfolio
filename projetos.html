ServicePlus – Sistema ERP Web (SaaS)

Clique aqui para mais informações

O ServicePlus é um sistema ERP web desenvolvido com foco na gestão completa de pequenos negócios, oferecendo controle centralizado de vendas, clientes, serviços e financeiro em uma única plataforma.

A aplicação foi construída utilizando PHP (Laravel), MySQL, JavaScript e Bootstrap, com interface responsiva e organizada para facilitar o uso no dia a dia.

Funcionalidades

  • Gestão de Produtos: Cadastro, edição e controle de estoque, incluindo marca, fornecedor e quantidades disponíveis.
  • Controle Financeiro: Registro de pagamentos, despesas e acompanhamento do fluxo de caixa.
  • Vendas de Produtos: Lançamento de vendas com atualização automática de estoque.
  • Gestão de Clientes: Cadastro e organização de clientes para acompanhamento de relacionamento.
  • Serviços e Mensalistas: Controle de serviços prestados e clientes recorrentes com pagamentos mensais.
  • Agenda: Organização de compromissos e atividades do negócio.
  • Tabela de Preços: Definição e gerenciamento de valores de produtos e serviços.
  • Fornecedores: Cadastro e vínculo com produtos.
  • Despesas Mensais: Controle recorrente de gastos fixos.
  • Sistema de Usuários: Controle de acesso ao sistema.

Diferenciais

  • Interface limpa e intuitiva
  • Estrutura modular baseada em boas práticas do Laravel
  • Integração entre módulos (ex: venda atualiza estoque automaticamente)
  • Projeto com arquitetura próxima a sistemas reais de mercado (ERP/SaaS)

Objetivo do Projeto

Desenvolver uma solução completa de gestão empresarial simulando um sistema real utilizado por pequenas empresas, aplicando conceitos de back-end, front-end, banco de dados e organização de software.
